开放与受控 ​

L1 和 L2 在开放环境采集：可穿戴设备、头环计算机、自由走动。L2 和 L3 用任务单固定物体摆放和步骤顺序。L3 还有受控环境：固定桌面、稳定光照、有时限 session，以满足高密度脑电、眼动和动捕对静止姿态的要求。

受控 session 分两段。运动想象（imagery）：屏幕变蓝，操作者坐直不动，在脑中预演任务，只记录脑电和注视。执行（execution）：屏幕变绿，同一任务真正执行，所有模态同时记录。run start、imagine、execute、run end 等标记写入记录，因此两段可以按同一时间基切出来。

从原始信号到发布表 ​

阶段做什么发布什么
同步与标定样本相对 episode 起点打时间戳；记录到达偏移；相机、tracker 与眼动仪按 session 标定。时间戳、内参、畸变、校正参数与 tracker 变换。
几何与运动深度由同步立体对经 FoundationStereo 得到；逐帧投影点云；手部在重叠视频窗口上重建并锚定到深度。深度、点云、头/腕/胸位姿与手指运动学。
注视受控 L3 由眼动仪以 200 Hz 实测；其余由视频模型以 30 Hz 预测。eye_gaze 与 eye_gaze_predict。
肌电零相位 20–450 Hz 带通与 50 Hz 梳状陷波；保留原始与去噪轨迹。*_emg_raw / *_emg_denoise。
脑电去均值、0.5–100 Hz 带通、50 Hz 陷波、坏导联检测、ICA、插值与平均参考。原始与清洗后的脑电表。
标注与质检Argus + Qwen 生成步骤标注，人工审核；每条 session 写完后逐流检查。结构化标注 JSON、qc_reports.jsonl；失败 session 重采。
